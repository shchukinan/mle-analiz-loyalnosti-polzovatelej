# Анализ лояльности пользователей Яндекс Афиши
Команда маркетинга хочет понимать, какие пользователи с большей вероятностью возвращаются на платформу. В проекте проводится исследовательский анализ данных покупок билетов: строится профиль пользователя, исследуются признаки первого заказа, проверяются продуктовые гипотезы статистическими тестами, формируются рекомендации для маркетинга.

## Установка и запуск
Для установки необходимых библиотек выполните команду в терминале, предварительно активировав виртуальное окружение Python:

`pip install -r requirements.txt`

Для формирования отчета выполните команду в терминале, находясь в корневой папке проекта:

`python3 main.py`

При запуске `python3 main.py` автоматически создается папка `reports/` с артефактами:

- `reports/final_report.txt` — сводный отчет: количество строк и столбцов, 
  доля дубликатов, статистика по числовым признакам, пропуски по столбцам
- `reports/figures/` — 8 визуализаций:
  - `01_users_by_segments.png` — пользователи по сегментам
  - `02_retention_by_segments.png` — доля возвратов по сегментам
  - `03_revenue_distribution_by_group.png` — выручка по группам
  - `04_weekday_retention.png` — возвраты по дню недели
  - `05_phik_heatmap.png` — тепловая карта корреляций φk
  - `06_top_phik_features.png` — топ-признаки по φk
  - `07_revenue_distribution.png` — распределение выручки
  - `08_tickets_distribution.png` — распределение числа билетов
